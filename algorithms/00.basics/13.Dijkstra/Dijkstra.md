# Dijkstra

가중치가 있는 그래프에서 한 시작점으로부터 다른 노드들까지의 최단 거리를 구하는 알고리즘.

핵심 조건:
#### 간선 가중치가 음수가 아니어야 함.
예를 들어:
```
A ---4--> B
A ---1--> C
C ---2--> B 
```

A에서 B로 바로 가면 4인데, 

```
A -> C -> B
1 + 2 = 3
```
이라서 최단거리는 3.
다익스트라는 이걸 priority_queue(min heap) 로 가장 가까운 노드부터 확정해 나감.
